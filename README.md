# Valley_Pharmacy
SQL data cleaning and analysis of a pharmacy sales dataset

## Data Issues Identified
When exploring the data there were several inconsitencies:
1. Inconsistent Date formats
2. Numeric data stored as DOUBLE
3. Mixed Text data types
4. Margin Calculation Reviewd

## Analysis Performed
Example of analysis performed after cleaning was:
1. Top medications by prescription volume
2. Revenue by insurance type
3. Average margin by drug

Skills demonstrated:
- Data cleaning in SQL
- Handling inconsistent date formats
- Converting data types
- Financial data normalization
- Query analysis

Tools used:
MySQL
MySQL Workbench
Excel
